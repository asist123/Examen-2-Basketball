# Examen-2-Basketball

Panel interactivo de rendimiento de jugadores de baloncesto, construido con React y Vite.

Incluye búsqueda con historial, estadísticas, ordenamiento, paginación, favoritos, tema claro y oscuro, y una vista de detalle por jugador.

Para iniciar el entorno local, ejecuta `npm install` y luego `npm run dev`. Para generar la versión de producción, usa `npm run build`.
